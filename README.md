# macal-ai-model — The Vizier (الوزير)

A personal AI agent for the MACAL / Empire English ecosystem: one door, one memory, many
hands. You tell it something from anywhere in the world and it does the work — reads the
repos, runs the checks, opens the PR, watches the server, remembers everything.

> **Status: SPEC STAGE.** No runtime code yet. Read
> [`BLUEPRINT.md`](./BLUEPRINT.md) for the vision and
> [`.kiro/specs/vizier-core/`](./.kiro/specs/vizier-core/) for requirements, design and the
> phased implementation plan.

## ⚠️ This repository is PUBLIC

No personal data, no life records, no memory contents, and no secrets belong here — ever.
Those live in a **separate private** repository (`macal-memory`) and in environment
variables on the server. This repo holds code, specs and documentation only.
